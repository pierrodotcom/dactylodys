# Le récit : brouillon à valider

Réponds par numéro : **oui**, **non**, ou ta version du texte.

Le fil : un petit dino (ton compagnon, que l'enfant nomme lui-même) visite cinq pays. Il avance parce que l'enfant tape. Le texte est dit à voix haute et illustré : phrases très courtes, un seul événement, une image facile à dessiner. Aucun reproche, rien qui dépende de la vitesse. Le nom du compagnon n'est jamais écrit dans les textes, pour que la voix n'ait pas à le dire.

Chaque texte est montré entre deux exercices : l'ouverture quand l'enfant entre dans le monde, la ligne d'une leçon quand il l'a réussie, la fin quand le monde est terminé.

## Au pays des dinosaures

1. **Ouverture** : « Ton petit dino se réveille. Il veut découvrir le monde ! » — image : le dino qui s'étire devant un grand paysage.
2. **Les œufs de dinosaure** : « Les œufs s'ouvrent : des bébés dinos sortent ! » — image : trois œufs ouverts, trois bébés.
3. **Le saut du diplodocus** : « Le diplodocus saute par-dessus la rivière. » — image : un long cou au-dessus de l'eau.
4. **Le nid du tricératops** : « Le tricératops te garde une place dans son nid. » — image : le nid avec une place vide.
5. **La mare du stégosaure** : « Le stégosaure fait un grand plouf dans la mare ! » — image : éclaboussures.
6. **Les mots du raptor** : « Le raptor te dit ses premiers mots. » — image : une bulle de BD avec « Salut ».
7. **Le rugissement du T-rex** : « Le T-rex rugit : bravo, tu as réussi ! » — image : le T-rex la bouche ouverte, les feuilles qui volent.
8. **Fin** : « Tous les dinos sont tes amis. En route vers la cuisine ! » — image : les cinq dinos qui font au revoir.

## La cuisine des gourmands

9. **Ouverture** : « Quelle bonne odeur ! Les gourmands t'invitent à cuisiner. » — image : une grande cuisine, des toques.
10. **La tartine toquée** : « La tartine est prête, avec un peu trop de beurre ! » — image : une tartine qui déborde.
11. **Le gâteau farfelu** : « Le gâteau farfelu monte, monte, monte ! » — image : un gâteau très haut, tout penché.
12. **La quiche qui rigole** : « La quiche rigole tellement qu'elle tremble. » — image : une quiche aux yeux fermés de rire.
13. **La casserole qui chante** : « La casserole chante une chanson de soupe. » — image : la casserole et des notes.
14. **Les épices surprises** : « Une pincée d'épices : surprise, ça sent bon ! » — image : de la poudre colorée en nuage.
15. **Fin** : « Le festin est servi. Direction le zoo ! » — image : une grande table pleine.

## Le zoo des drôles d'animaux

16. **Ouverture** : « Bienvenue au zoo ! Les animaux sont tous un peu drôles. » — image : l'entrée du zoo, une pancarte.
17. **La girafe au long cou** : « La girafe te voit de tout là-haut. » — image : la tête de la girafe au-dessus des arbres.
18. **Le bal de la vache** : « La vache danse au bal, la queue en l'air ! » — image : la vache en robe qui tourne.
19. **Le yak mystère** : « Le yak garde un mystère… tu l'as trouvé ! » — image : le yak qui sort un petit paquet de sa fourrure.
20. **Le zèbre à rayures** : « Le zèbre te montre ses belles rayures. » — image : le zèbre de profil, fier.
21. **Fin** : « Les animaux applaudissent. Cap sur les étoiles ! » — image : tous les animaux qui lèvent le museau vers le ciel.

## Cap sur les étoiles

22. **Ouverture** : « Trois, deux, un… ton dino décolle vers les étoiles ! » — image : la fusée au départ.
23. **Le café de la Lune** : « Sur la Lune, un petit café t'attend. » — image : une table et une tasse sur un sol gris.
24. **La comète pressée** : « La comète passe : vite, vite, vite ! » — image : une comète avec une longue queue.
25. **Les géantes de la galaxie** : « Les géantes de la galaxie te saluent, très grandes. » — image : de grandes planètes qui se penchent.
26. **Pause sur la planète Virgule** : « Sur la planète Virgule, on respire un instant. » — image : le dino assis sur une planète en forme de virgule.
27. **Fin** : « Les étoiles brillent pour toi. Allons faire une course ! » — image : une pluie d'étoiles douces.

## Le grand circuit des bolides

28. **Ouverture** : « Vroum ! Le grand circuit des bolides commence. » — image : une piste, un drapeau à damier.
29. **Le klaxon rigolo** : « Le klaxon fait pouet ! Même pas peur. » — image : une voiture avec un klaxon géant.
30. **Le train aux wagons accrochés** : « Le train accroche tous ses wagons. » — image : un long train qui s'allonge.
31. **Le chapeau du pilote** : « Le pilote met son chapeau. Il est beau ! » — image : un pilote au chapeau à plume.
32. **Le casque du copilote** : « Le copilote met son casque : c'est parti ! » — image : un casque trop grand.
33. **Le camion aux deux yeux** : « Le camion ouvre ses deux gros yeux. » — image : un camion dont les phares sont des yeux.
34. **Fin** : « Tu as fini le grand tour. Ton dino est fier de toi ! » — image : le dino sur un podium, médaille au cou.

## Deux choses à décider

A. **Enregistrement** : ces 34 textes s'ajoutent aux 25 déjà à enregistrer (24 consignes et le rappel). Si c'est trop, on enregistre d'abord les 10 ouvertures et fins (numéros 1, 8, 9, 15, 16, 21, 22, 27, 28, 34), et les lignes de leçon restent écrites pour l'instant. Que préfères-tu ?
B. **Longueur** : les phrases font de 6 à 11 mots. Trop long pour un enfant qui ne lit pas ? Dis-moi les numéros à raccourcir.
