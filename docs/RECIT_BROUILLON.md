# Le récit (version 2, validée)

**Validé par le porteur le 2026-10-17** (« ok pour tout ») : ces 34 textes sont ceux du lot S2 (ADR-042).

**Ce qui change** (demande du porteur : le ton faisait « 8 ans ») : même longueur et mots simples, mais de l'humour pince-sans-rire, un compagnon gourmand et sûr de lui, plus de « petit », « bébé » ni « bravo » (le bilan et les étoiles félicitent déjà), et un fil conducteur : **le carnet de voyage** du compagnon, dont chaque monde remplit une page.

Le fil : le dino (ton compagnon) fait le tour de cinq pays. Il avance parce que l'enfant tape. Le texte est dit à voix haute et illustré : phrases courtes, un seul événement, une image facile à dessiner. Aucun reproche, rien qui dépende de la vitesse. Le nom du compagnon n'apparaît jamais dans le récit (choix A du porteur).

Chaque texte est montré entre deux exercices : l'ouverture quand l'enfant entre dans le monde, la ligne d'une leçon quand il l'a réussie, la fin quand le monde est terminé.

## Au pays des dinosaures

1. **Ouverture** : « Ton dino part en voyage. Son carnet est encore tout vide. » — image : le dino, sac au dos, qui ouvre un carnet aux pages blanches.
2. **Les œufs de dinosaure** : « Les œufs éclosent. Les bébés réclament déjà leur goûter. » — image : trois bébés dinos, bouche grande ouverte, une serviette autour du cou.
3. **Le saut du diplodocus** : « Le diplodocus saute la rivière. Sa queue, elle, reste dans l'eau. » — image : le long corps au-dessus de l'eau, le bout de la queue qui trempe.
4. **Le nid du tricératops** : « Pour entrer dans le nid, il faut un mot de passe. » — image : le tricératops devant son nid, une pancarte avec un cadenas.
5. **La mare du stégosaure** : « Le stégosaure plonge dans la mare. La mare est maintenant vide. » — image : le stégosaure trempé, l'eau partout autour, la mare à sec.
6. **Les mots du raptor** : « Le raptor écrit son tout premier mot : miam. » — image : le raptor, un crayon à la patte, « miam » écrit sur un rocher.
7. **Le rugissement du T-rex** : « Le T-rex rugit si fort que sa casquette s'envole. » — image : le T-rex bouche ouverte, sa casquette dans les airs.
8. **Fin** : « Première page du carnet : remplie. Prochaine étape, la cuisine. » — image : le dino qui colle une photo des dinos dans son carnet.

## La cuisine des gourmands

10. **La tartine toquée** : « La tartine porte une toque. Elle se prend pour un chef. » — image : une tartine coiffée d'une toque, l'air sérieux.
11. **Le gâteau farfelu** : « Le gâteau monte si haut qu'il touche le plafond. » — image : un gâteau penché qui s'écrase contre le plafond.
12. **La quiche qui rigole** : « La quiche rigole. Personne ne sait pourquoi, même pas elle. » — image : une quiche pliée de rire, les autres plats perplexes.
13. **La casserole qui chante** : « La casserole chante faux. Le chef se bouche les oreilles. » — image : la casserole bouche ouverte, des notes tordues, le chef mains sur les oreilles.
14. **Les épices surprises** : « Une pincée d'épices, et ton dino éternue des étincelles. » — image : le dino qui éternue un nuage d'étincelles colorées.
15. **Fin** : « Ton dino a tout goûté. Deux fois. Page deux : remplie. » — image : le dino au ventre rond, une tache de sauce sur la page du carnet.

30. **Le train aux wagons accrochés** : « Le dernier wagon du train arrive avec une heure de retard. » — image : un train très long, le dernier wagon loin derrière, une horloge.

34. **Fin** : « Dernière page du carnet : remplie. La suite, c'est toi qui l'écris. » — image : le carnet fermé, plein à craquer, sur le podium.
