# « œ », point-virgule et guillemets

**Validé par le porteur le 2026-10-18** (« oui à tout », recommandations retenues : n° 1 pour « œ »), réalisé selon l'ADR-045. Les deux consignes ont été raccourcies à une phrase de 120 caractères au plus (règle des consignes) :
- *Pause sur la planète Virgule* : « Ton index tape la virgule à droite de N, ton majeur le point-virgule à côté ; avec Maj, cette touche fait le point. »
- *Le klaxon rigolo* : « Maj et la virgule donnent le point d'interrogation, le point d'exclamation est tout à droite, les guillemets sur le 3. »

## A. La ligature « œ »

Constat : sur un clavier AZERTY de PC (le tien, celui des écoles), **« œ » n'a pas de touche**. On ne l'obtient qu'avec Alt + 0156 sur le pavé numérique (absent des portables), ou parce que Word remplace « oe » tout seul dans certains mots. Sur Mac, c'est Option + O. Les adultes tapent presque tous « oe ».

1. **Ne pas faire taper « œ »** (recommandé) : on continue à éviter les mots qui le contiennent (« œuf », « cœur », « sœur ») dans les exercices ; il reste écrit dans les titres, que l'enfant ne tape pas (« Les œufs de dinosaure »). Rien à apprendre qui n'existe pas sur son clavier.
2. Accepter « oe » à la place de « œ » : le mot s'affiche « œuf », l'enfant tape o puis e, le jeu l'accepte. Les mots avec « œ » reviennent dans les exercices, mais l'enfant voit une lettre et en tape deux, ce qui peut le dérouter.
3. Écrire « oeuf » dans les exercices : plus simple, mais c'est une faute d'orthographe montrée à des enfants qui apprennent à écrire.

## B. Le point-virgule « ; »

Sur AZERTY PC, il est sur la touche à droite de la virgule (sans Maj). Comme pour « ? », « ! » et « : », une espace avant (ADR-023).

4. **Où l'apprendre** : dans la leçon *Pause sur la planète Virgule*, avec la virgule et le point (« la virgule, le point… et le point-virgule »).
5. **Consigne de la leçon** (à réenregistrer à la voix) : « Ton index droit tape la virgule, à droite de N. Ton majeur tape le point-virgule juste à côté ; avec Maj, cette touche fait le point. »

Phrases proposées (toutes écrites avec les lettres déjà apprises à cette leçon) :

6. Le chat dort ; la souris danse.
7. Il pleut ; le canard sourit.
8. La soupe est chaude ; on souffle.
9. Le robot tombe ; il se relève.
10. La lune brille ; le loup chante.
11. Le vent souffle ; le chapeau vole.
12. La porte grince ; le chat sursaute.
13. La cloche sonne ; la classe sort.
14. Le clown glisse ; tout le monde rit.

## C. Les guillemets

Sur AZERTY PC, seuls les guillemets droits **"** existent (touche 3, sans Maj) ; les guillemets français « » n'ont pas de touche, comme « œ ».

15. **Faire taper les guillemets droits "** (recommandé), sans espace à l'intérieur : `Le perroquet dit "bonjour".`
16. **Où l'apprendre** : dans la leçon *Le klaxon rigolo*, avec « ? » et « ! » (le klaxon « parle »).
17. **Consigne de la leçon** (à réenregistrer) : « Le point d'interrogation se tape avec Maj sur la touche de la virgule, le point d'exclamation tout à droite. Les guillemets sont sur la touche 3. »

Phrases proposées :

18. Le perroquet dit "bonjour".
19. Le chien aboie "ouaf".
20. Le panneau dit "attention".
21. Sur la porte, on lit "entrez".
22. Le bébé dragon réclame "encore".
23. Le chat répond "miaou" et s'en va.
24. Le klaxon fait "pouet" ; tout le monde rit. *(utilise aussi « ; », appris juste avant)*
25. Le robot dit "bip" puis il s'endort.
