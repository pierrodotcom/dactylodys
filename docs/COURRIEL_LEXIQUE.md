Le code est publié sous licence AGPL-3.0, les contenus sous licence CC BY-SA 4.0, sans publicité ni collecte de données : https://github.com/pierrodotcom/dactylodys

Pour choisir des mots courants que de jeunes enfants connaissent, j'ai utilisé la table de Lexique 3.83 (fréquences des livres et des films, part d'adultes connaissant le mot). Je n'en ai gardé qu'une liste filtrée d'environ 900 mots (forme, thème, niveau de fréquence), publiée avec le projet. Lexique est cité dans le fichier des attributions : « Boris New, Christophe Pallier et al., Lexique 3.83, www.lexique.org ».
